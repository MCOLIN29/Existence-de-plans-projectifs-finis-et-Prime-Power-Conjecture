Vous trouverez dans ce dépôt deux fichiers réalisés dans le cadre d'une candidature au Prix Fermat Junior : un document PDF et un programme Python.

Le document PDF porte sur l'existence des plans projectifs finis et sur la conjecture associée (Prime Power Conjecture).

Le programme Python correspond au code associé à la remarque 13 du document PDF.

**Erratum** : Après relecture de mon code, je me suis rendu compte qu'une erreur de comptage conduisait à compter deux fois l'inexistence du plan projectif fini d'ordre 6. Par conséquent, dans la remarque 13 du PDF, le nombre d'ordres pour lesquels l'inexistence est démontrée est en réalité  690419 (au lieu de 690420), tandis que le nombre d'ordres pour lesquels on ne peut pas conclure est 1160345 (au lieu de 1160344). Cette erreur ne modifie toutefois pas le raisonnement mathématique de la remarque. Par souci de transparence, je tiens néanmoins à la signaler. Le PDF et le code sont d'ores et déjà corrigés. Toutefois, le PDF ayant déjà été soumis dans le cadre de ma candidature avec cette coquille, je conserve cet erratum jusqu'à la fin de l'évaluation des candidatures.
