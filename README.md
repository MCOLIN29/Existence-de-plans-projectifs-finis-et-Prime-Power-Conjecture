Vous trouverez dans ce dépôt les fichiers réalisés dans le cadre d'une candidature au Prix Fermat Junior : le document PDF et le programme Python associé.

Le document PDF porte sur l'existence des plans projectifs finis et sur la conjecture associée (Prime Power Conjecture).

Le programme Python correspond au code associé à la Remarque 13 du document PDF.

**Erratum** : Après relecture de mon code, je me suis rendu compte qu'une erreur de comptage conduisait à compter deux fois l'inexistence du plan projectif fini d'ordre 6. Par conséquent, dans la Remarque 13 du PDF, le nombre d'ordres pour lesquels l'inexistence est démontrée est en réalité 690 419 (au lieu de 690 420), tandis que le nombre d'ordres pour lesquels on ne peut pas conclure est 1 160 345 (au lieu de 1 160 344). 

Cette coquille numérique ne modifie en rien le raisonnement mathématique ni la validité des preuves. Par souci de transparence et de rigueur, la version du PDF présente sur ce dépôt ainsi que le code Python intègrent désormais cette correction.
